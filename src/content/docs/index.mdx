A shared reference for economic research: the papers behind an argument, the data used to test it, and the findings the evidence supports.

## Research topics

- **[Economics of leisure](/papers/leisure/):** how time is allocated across work, home production, and leisure, and why the value of free time depends on its circumstances.
- **[Closed economies and trade](/papers/trade/):** what historical episodes, cross-country studies, and models imply about income, welfare, and GDP growth.

The collection contains **15 core papers and one review**, plus guides to the main data sources. [Source and editorial notes](/guides/sources/) explain the discussion's provenance and the verification still needed.

## Using this wiki

Start with a topic's paper register, use the data guides to choose sources, and read the findings pages for a concise evidence map. Keep population, period, outcome definition, and method in view when comparing results.
